LUA SCRIPT

This is plain Lua — if you know Lua, you already know this. Variables, loops, functions, print(), math/string/table, coroutines: all normal. Only the extreme stuff is removed (no io, no os.execute, no loading outside code). The game powers are optional extras: define onTick(dt) / onPad() to react to the world, and call spinCoins(delta), launch(power), playTone(freq), setDisco(i, 0xRRGGBB), playSound("name") when you want them. Prefer namespaces? They all exist as bt.onTick, bt.spinCoins, etc. too — same functions.
