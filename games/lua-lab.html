* LUA LAB 🌙

* a game where you code in lua. the lua is fully real — but it lives in a sandbox: no files, no internet, no touching the arcade. all it can do is print, draw, and play. finish a run with 0 errors = +400 points. errors void the run. how rich can clean code make you?

🏆 points: 0 ✅ clean runs: 0 * ready.

* HOW IT PAYS

* press ▶ run. if your script finishes with 0 errors, or runs a full 2 seconds error-free with on_tick, you bank +400. one bank per run. any error before the bank = the run pays nothing. your points total is your leaderboard score.

* THE LUA LAB API (everything your code can touch)

  • print(...) — write to the console
  • input() — pause and ask the player for a line of text (returns a string)
  • draw.clear() · draw.color(r, g, b) · draw.rect(x, y, w, h)
  • draw.circle(x, y, r) · draw.line(x1, y1, x2, y2) · draw.text("hi", x, y)
  • draw.W = 480 · draw.H = 320 — the canvas size
  • function on_tick(dt) — runs ~30×/second while your script lives
  • function on_key(key) — "left", "right", "up", "down", "space", "a", …
  • mouse.x · mouse.y · mouse.down — read the mouse/touch
  • plus all of lua itself: tables, functions, coroutines, math, string…
  • NOT in the sandbox: os, io, files, require, the internet, the arcade. they were never built.
